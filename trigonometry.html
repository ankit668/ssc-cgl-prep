📐 SSC CGL Trigonometry Cheat Sheet

1. Basic Ratios & Relationships

For a right-angled triangle with angle \( heta \):

  • \( \sin heta = rac{Perpendicular}{Hypotenuse} \)
  • \( \cos heta = rac{Base}{Hypotenuse} \)
  • \( an heta = rac{Perpendicular}{Base} \)
  • \( \csc heta = rac{1}{\sin heta} \)
  • \( \sec heta = rac{1}{\cos heta} \)
  • \( \cot heta = rac{1}{ an heta} \)

3. Fundamental Identities

  • \( \sin^2 heta + \cos^2 heta = 1 \)
  • \( 1 + an^2 heta = \sec^2 heta \)   \(\Rightarrow \sec^2 heta - an^2 heta = 1 \)
  • \( 1 + \cot^2 heta = \csc^2 heta \)   \(\Rightarrow \csc^2 heta - \cot^2 heta = 1 \)

4. Advanced SSC Shortcuts (Highly Tested)

If \( A + B = 90^\circ \) (Complementary Angles):

  • \( \sin A = \cos B \)   and   \( \sec A = \csc B \)
  • \( an A = \cot B \)   \(\Rightarrow an A imes an B = 1 \)
  • \( \sin^2 A + \sin^2 B = 1 \)   and   \( \cos^2 A + \cos^2 B = 1 \)

Golden SSC Multipliers:

  • \( \sin heta \cdot \sin(60^\circ- heta) \cdot \sin(60^\circ+ heta) = rac{1}{4} \sin 3 heta \)
  • \( \cos heta \cdot \cos(60^\circ- heta) \cdot \cos(60^\circ+ heta) = rac{1}{4} \cos 3 heta \)
  • \( an heta \cdot an(60^\circ- heta) \cdot an(60^\circ+ heta) = an 3 heta \)

🎯 SSC CGL Previous Year Questions (PYQs)

Type 1: Golden Multipliers
Q (CGL 2023): What is the value of \( \cos 20^\circ \cos 40^\circ \cos 80^\circ \)?
Solution: Fits the form \( \cos heta \cdot \cos(60- heta) \cdot \cos(60+ heta) \) where \( heta = 20^\circ \). Result = \( rac{1}{4} \cos 3(20^\circ) = rac{1}{4} \cos 60^\circ = rac{1}{4} imes rac{1}{2} = rac{1}{8} \).
Type 2: Complementary Angles (\(A+B=90^\circ\))
Q (CGL Tier-2 2022): Evaluate: \( an 1^\circ \cdot an 2^\circ \cdot an 3^\circ \dots an 89^\circ \)
Solution: Since \( A + B = 90^\circ \Rightarrow an A \cdot an B = 1 \). Pairs like \( an 1^\circ an 89^\circ = 1 \). Only \( an 45^\circ \) is left in the middle, which is 1. Answer = 1.
Q (CGL 2021): Find the value of \( \sin^2 10^\circ + \sin^2 20^\circ + \dots + \sin^2 80^\circ + \sin^2 90^\circ \)
Solution: Since \( A + B = 90^\circ \Rightarrow \sin^2 A + \sin^2 B = 1 \). Number of terms from 10 to 80 is 8 terms (4 pairs). So 4 pairs = 4. Plus \( \sin^2 90^\circ = 1 \). Total = 5.
Type 3: Identity Manipulation
Q (CGL 2020): If \( \sec heta + an heta = P \), what is \( \sec heta - an heta \)?
Solution: Using identity \( \sec^2 heta - an^2 heta = 1 \Rightarrow (\sec heta + an heta)(\sec heta - an heta) = 1 \). Therefore, \( \sec heta - an heta = rac{1}{P} \).
Q (CGL Tier-2): If \( \sec heta + an heta = 5 \), find \( \sin heta \).
Solution: \( \sec heta - an heta = rac{1}{5} \). Adding them gives \( 2\sec heta = 5 + rac{1}{5} = rac{26}{5} \Rightarrow \sec heta = rac{13}{5} \). Hypotenuse = 13, Base = 5. By Pythagoras triplet (5, 12, 13), Perpendicular = 12. Thus \( \sin heta = rac{12}{13} \).
Type 4: Max/Min Values
Q (CGL 2019): Find the maximum value of \( 3 \sin heta + 4 \cos heta \).
Solution: Format is \( a \sin heta + b \cos heta \). Max value = \( \sqrt{a^2 + b^2} = \sqrt{3^2 + 4^2} = \sqrt{25} = 5 \).
Q (CGL 2023): Find the minimum value of \( 4 an^2 heta + 9 \cot^2 heta \).
Solution: For \( a an^2 heta + b \cot^2 heta \), the minimum value (using AM-GM inequality) is \( 2\sqrt{ab} = 2\sqrt{4 imes 9} = 2\sqrt{36} = 12 \).
